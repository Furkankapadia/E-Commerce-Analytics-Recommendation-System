E-Commerce Predictive Analytics Model

An advanced business intelligence & machine learning pipeline that forecasts sales, clusters customer segments, and mines cross-selling association rules. Built on SQLite/FastAPI and Vanilla JS with 100% automated data mapping.

Python Pandas NumPy Scikit-learn Apriori Mining Linear Regression SQLite FastAPI Vanilla CSS

Dataset Ingestion

Parses multi-source transaction logs (e.g. Olist, Zomato, or custom sales sheets). Utilizes smart regex keyword checks to map disparate columns automatically to uniform fields.

ML Analytics Engines

Applies Linear Regression on monthly intervals to estimate revenues. Clusters user databases using Recency, Frequency, and Monetary percentile grouping.

Apriori Cross-Selling

Extracts unique buyer product category baskets and evaluates itemsets. Generates support, confidence, and lift rules to guide cross-selling promotions.
